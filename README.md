# Aire Caliente · app instalable (PWA)

Recetario para freidora de aire que se instala en el celular como una app y funciona sin internet.

## Cómo publicarla en GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `aire-caliente`).
2. Subí todo el contenido de esta carpeta (los 8 archivos: index.html, manifest.webmanifest, sw.js y los íconos .png) a la raíz del repo.
3. En el repo: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
4. En un minuto queda en `https://TU-USUARIO.github.io/aire-caliente/`.

También funciona en Netlify (arrastrando la carpeta a app.netlify.com/drop) o en cualquier hosting con HTTPS.

## Cómo instalarla

- **Android (Chrome):** abrí la página y tocá el botón "📲 Instalar la app" de la portada, o menú ⋮ → "Instalar app".
- **iPhone (Safari):** botón Compartir → "Agregar a inicio".
- **Computadora (Chrome / Edge):** ícono de instalar en la barra de direcciones.

## Funciona sin internet

La primera vez que se abre con conexión, la app guarda todo lo necesario. Después abre igual sin datos.
Favoritas, recetas hechas, puntajes, notas y lista de compras se guardan en el teléfono.

## Para actualizar

Reemplazá los archivos y volvé a subirlos. Quien tenga la app instalada ve el aviso "Hay una versión nueva".
